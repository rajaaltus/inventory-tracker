## Critical Folders

| Folder             | Purpose                                           | Intern Focus |
| ------------------ | ------------------------------------------------- | ------------ |
| `app/`             | All page routes — each folder = a URL path        | High         |
| `src/convex/`      | Backend logic — schema, auth, queries, mutations   | High         |
| `components/`      | Shared UI components                               | High         |
| `components/ui/`   | Pre-built shadcn/ui components (don't edit much)   | Low          |
| `lib/`             | Utility functions                                   | Low          |
| `public/`          | Static assets served at root URL                    | Low          |

## Entry Points

- **App Entry:** `app/layout.tsx` — Root layout that wraps all pages
- **Main Page:** `app/page.tsx` — Landing page users see first
- **Dashboard:** `app/dashboard/page.tsx` — Primary feature page
- **Backend Entry:** `src/convex/schema.ts` — Database schema definition
- **Auth Entry:** `src/convex/auth.ts` — Authentication setup
- **Route Guard:** `middleware.ts` — Runs before every request
